# Morse Signal Game

A real-time multiplayer morse code communication game where players send encoded signals to each other using dots, dashes, and spaces. Good for learning morse code with friends.

## What This App Can DO?

**Real-time Communication**: Instant message relay via WebSocket connections
**Morse Code Translation**: Automatic conversion of Morse code to readable text 
**Multiplayer Support**: Connect multiple players at once
**Interactive Controls**: Support for both keyboard and mouse/touch input
**Live Preview**: View your Morse code in real-time as it is converted to text
**Player Management**: Monitor connected players.
**Responsive Design**:  Compatible with mobile, tablet, and desktop

##  How to Play

      TAKE A CHILL PILL DUDE JUST OPEN AND PLAY

## Technical Details

### Tech Stack
- **Backend**: Node.js + Express + Socket.IO
- **Frontend**: Vanilla HTML5, CSS3, JavaScript
- **Real-time**: WebSocket connections via Socket.IO
